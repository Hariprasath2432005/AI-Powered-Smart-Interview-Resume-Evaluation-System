# 🤖 AI-Powered Smart Interview & Resume Evaluation System

An intelligent AI-powered platform that evaluates resumes and conducts 
smart interview assessments using Groq LLM and advanced NLP techniques.

## ✨ Features
- 📄 Smart Resume parsing & analysis
- 🎯 AI-powered interview question generation
- 📊 Candidate scoring & evaluation
- 🧠 Groq LLM integration for intelligent responses
- 🔍 Skills extraction & matching
- 📈 Detailed evaluation reports
